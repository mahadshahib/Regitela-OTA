Install Regitela

Only the 19 devices registered in the signing profile can install this build. Enable Developer Mode if requested. If iOS asks you to trust the developer, use Settings → General → VPN & Device Management.

The App Group is preserved: group.com.mahadshahib.regitela. After launching, the Log tab should show this group rather than “app group: none”.

Upstream supports iOS 26.0–26.7.2 and 27.0–27.2. Supervised Mode, Region and Browse require iOS 27. Back up before using these tools; do not enable Supervised Mode on an MDM-managed device.
